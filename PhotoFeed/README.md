# 刷相册 PhotoFeed

纯本地、无网络、无账号的 Android 相册浏览应用。像刷短视频一样上下滑动浏览本机的照片、视频和动图，过程中可以删除不需要的媒体。

## 功能

- 顶部栏：左边设置、中间三个频道（视频 / 照片 / 动图，首次启动进入中间的「照片」）、右边删除
- 竖向滑动浏览，固定种子洗牌，最近看过的 300 张排到队尾
- 照片 / 长截图：按原始宽高比完整显示、不放大裁切（不再用 `centerCrop`）；双指捏合可放大到 4 倍并拖动查看，缩回或双击恢复原大小；长截图（长短边比 ≥ 2.4）默认短边铺满、长边拖动查看，双击切换「适应整屏」，滑到长边尽头才翻页
- 无限刷：一轮内不重复，快到队尾时用新种子重新洗牌自动接上下一轮，永远刷不到底；删除过的媒体不会在下一轮复活
- 频道切换：横向拖动 / 甩动门槛提高 3 倍，竖向翻页期间锁定频道切换，杜绝斜滑误触；长横滑与标签点击仍可正常切频道
- 视频：只有切到「视频」频道才自动播放且默认有声音；按真实宽高比在屏幕中上下居中，不同机型都完整显示不裁切；点击画面暂停/继续。**底部控制栏**（仅视频频道）：播放/暂停、当前时间、可拖动进度条（快进/快退）、总时长与倍速：点速度按钮（仪表盘图标）弹出横向档位条（0.5x/1.0x/1.5x/2.0x/3.0x，当前档高亮），点选即生效、再点收起，点击画面唤出、约 3 秒无操作自动隐藏
- 横版视频：画面下边缘居中的「全屏观看」胶囊按钮（图标 + 文字），竖版视频不显示；点一下进入真正的沉浸式横屏全屏：系统状态栏（时间 / 电量）与导航栏一起隐藏、内容铺满整个物理屏幕，视频按真实宽高比完整显示不裁切，并以整个屏幕中心居中（上下左右黑边对称）；播放与声音不中断，应用顶部栏与全屏按钮全部隐藏，左上角返回或系统返回键退出，退出后状态栏恢复
- 非当前频道、切走频道或 App 退到后台，一律不播放也不出声
- 删除：点右上角删除立即唤起系统删除确认，确认后即时生效；文件移入系统 / 相册回收站可随时恢复，无 5 秒撤销窗口
- 动图（动态照片 / Live Photo）：进入「动图」频道自动循环播放视频半体并保留原声（苹果 Live Photo 带音轨），静帧与视频均完整显示不裁切；**翻页不闪屏**——静帧作封面盖住播放器、绑定阶段预准备视频、`onRenderedFirstFrame` 后才揭封面、跨页复用同一个 ExoPlayer 不重建 surface；支持 JPEG 内嵌 MP4、ROM 私有标记、静帧与独立 MP4/MOV 按内容 ID 配对；视频半体不在媒体库时给出恢复提示
- 设置页：「重新识别」为后台增量识别（点完即可退出设置页继续刷，任务跑在进程作用域不随 Activity 销毁取消；完成后写缓存并刷新动图频道）；按 `mediaKey` 缓存已扫过的文件与负结果，只解析新增媒体；Live Photo 内容 ID 也持久化缓存，权限透明说明
- 备注 / 喜欢 / 分享 / 备注导入导出：功能已移除，界面不再提供入口

## 功能与权限映射

| 功能 | 需要权限 | 不需要权限 |
|---|---|---|
| 浏览照片/视频/动图 | 读媒体权限 | 存储写、位置 |
| 播放视频/动图 | 无 | INTERNET、WAKE_LOCK |
| 删除照片 | 无（系统删除请求） | WRITE/MANAGE_EXTERNAL_STORAGE |
| 显示拍摄日期 | 无（DATE_TAKEN） | ACCESS_MEDIA_LOCATION |

## 申请的权限（全部，仅四项）

- `READ_MEDIA_IMAGES` —— Android 13+ 读取照片
- `READ_MEDIA_VIDEO` —— Android 13+ 读取视频
- `READ_MEDIA_VISUAL_USER_SELECTED` —— Android 14 部分授权
- `READ_EXTERNAL_STORAGE`（`maxSdkVersion=32`）—— Android 12 及以下兜底

**本应用不申请**：网络、位置、通讯录、短信、电话、相机、麦克风、已安装应用列表。
`INTERNET`、`ACCESS_NETWORK_STATE`、`WAKE_LOCK` 在 Manifest 中用 `tools:node="remove"` 强制移除。

## 隐私声明

所有数据仅保存在本机。应用没有 `INTERNET` 权限，物理上无法联网或上传任何内容，也不提供数据导出与分享。

## 技术栈

Kotlin · minSdk 29 · targetSdk 34 · ViewPager2 + RecyclerView(PagerSnapHelper) · Glide 4.16 · Media3 1.3.1 · Room 2.6.1 · Coroutines/Flow

## 构建

```bash
# 需要 JDK 17、Android SDK Platform 34、Build-Tools 34.0.0
./gradlew assembleDebug        # 调试包
./gradlew assembleRelease      # 发布包
./gradlew checkPermissions     # 白名单权限审计，多一个就构建失败
```

权限审计（发布前必跑）：

```bash
aapt2 dump permissions app-release.apk
```

期望输出只有上面四项白名单权限。

## 真机验证结论与已知边界

已在两台 vivo 真机上通过 USB 调试完成全量回归：vivo V2123A / Android 11 (API 30)，以及 vivo V2361A / Android 16 (API 36, 1260x2800)。

1. 冷启动连续多次均落在中间「照片」频道；非当前频道没有 `state:started` 音轨。
2. 用户真实横屏素材（16:9、2.4:1、2.76:1、4K、AVI、MKV、HEVC）横屏全屏后状态栏消失、`android:id/content` 铺满 [0,0][2342,1080]，FIT 完整居中不裁切，播放与声音不中断。
3. 照片 / 动图静帧完整比例显示；长截图拖动、双击适应整屏、边缘翻页均正常。
4. 苹果 Live Photo 静帧 + 独立 MP4 按内容 ID 配对后可自动循环播放，`dumpsys audio` 显示本应用 `state:started` 的 `USAGE_MEDIA` 音轨。
5. 删除即时唤起系统确认；点「拒绝」取消后应用正常恢复、媒体未被删除。
6. 连续翻页 20+ 页无 OOM / SIGABRT / PlaybackException；`checkPermissions` 与 `aapt2 dump permissions` 均只有四项白名单权限、无 `INTERNET`。
7. 缩放：真机观察到放大后照片内容明显变大并出现「已放大」提示，双击 / 缩回后提示消失、画面回到原始比例；放大态不会误翻页或误切频道。
8. 频道误触：80px 短横滑、dx=120 / dy=-800 的斜向上滑均不切频道；700px 长横滑正常切到相邻频道，标签点击正常。
9. 无限刷：照片频道共 79 张，连续翻 100 页后仍无空态，Room 会话表 `photo.lastIndex=99`，证明已自动追加第二轮并跨轮继续浏览。
10. 增量识别：读取应用私有 `SharedPreferences` 确认 `motion_scanned=78`、`motion_linked_ids=115`（78 图 + 37 视频，负结果也缓存）；新增 1 张照片再识别后变为 79 / 116，即只解析了这 1 张。冷缓存全量识别时按钮持续处于「识别中」12 个采样周期，热缓存第一次采样即完成。
11. Android 16 新机回归（1568 张图 / 207 个视频）：设置按钮文案为「重新识别」；点识别后**立刻退出设置页并切到视频频道刷两张**，12s 后私有缓存 `motion_scanned` 1568→1588、`motion_linked_ids` 1775→1795，正好扫完 20 张新增文件，证明后台任务不随 Activity 销毁取消且仍是增量。动图频道连续 4 轮翻页共采 34 帧截屏，无接近全黑的闪帧（最低平均亮度 28.6、可见像素仍 ≥32.6%）；`dumpsys audio` 为 `state:started / USAGE_MEDIA`。横屏全屏 `content=[0,0][2800,1260]`、`player=[560,0][2240,1260]` 居中不裁切、topBar 消失、btnBack 可见，返回后状态栏与「全屏观看」恢复；短横滑 / 斜滑不切频道、800px 长横滑正常切；双击缩放提示在放大与复位间交替；删除按钮 900ms 内弹出系统确认，点「拒绝」后媒体未删。

12. 视频控制栏（Android 16 新机回归补充）：仅「视频」频道出现的底部控制栏已逐帧真机截图验证——含播放/暂停、当前时间、可拖动进度条、总时长与倍速。倍速按 1.0x→1.5x→2.0x→3.0x→0.5x→1.0x 循环（五帧截图逐一确认）；拖动进度条后播放头从 00:02 跳到 00:08（总时长 8s）并停在最右，证明 `seekTo` 生效；点击画面唤出控制栏、约 3 秒无操作自动隐藏（截图确认已隐藏）；切新视频倍速复位 1.0x。控制栏自身 `clickable/focusable` 消费触摸不穿透画面，照片/动图频道不显示。

仍需注意的边界：

- Android 11+ 分区存储下，第三方应用无法按原始路径读取系统相册的隐藏回收站目录（如 `.vivoFileRecycleBin/`）。若 Live Photo 的视频半体被移入其中，本应用只能显示静帧并提示恢复；系统相册能播放是因为系统应用权限更高。
- 双指手势无法用 `adb` 注入：测试机未 root，`sendevent /dev/input/event3` 返回 `Permission denied`。真机改用双击验证**同一条 `applyUserScale` 缩放链路**，`ScaleGestureDetector` 的接入已通过编译与代码审查确认。
- 未覆盖：其他品牌 ROM 的 Motion Photo 私有标记、Android 10 上 `RecoverableSecurityException` 的真实回调顺序、万张级图库首次查询耗时与内存占用。
